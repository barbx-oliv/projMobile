## 1. Introdução 

### 1.1 Finalidade 

Este documento especifíca os requisitos e a arquitetura do aplicativo móvel de Gerenciamento de Consultas de Entregas de Encomenda. O sistema utiliza o framework Flutter para a interface de usuário e lógica de controle, e o banco de dados SQLite para persistência local de dados.
